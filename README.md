# My Portfolio Site

## Files
- `index.html` — the page content (text, structure, links to your images)
- `style.css` — all the colors, fonts, spacing, layout
- `script.js` — makes the mobile menu button work
- `images/` — put your artwork here

## To customize
1. Open `index.html` in a text editor. Replace "Jordan Cruz" with your name,
   rewrite the hero text, and replace the project titles/captions in the
   `.grid` section with your own project names.
2. Put your image files inside the `images/` folder. Name them anything —
   just make sure the `src="images/your-file-name.jpg"` in `index.html`
   matches the actual file name exactly (including capitalization).
3. Open `style.css` if you want to change colors. They're all defined once
   at the top in the `:root { }` block, so changing `--pink` there changes
   it everywhere on the site.
4. Update the email and social links in the contact section.

## To preview
Double-click `index.html` — it opens in your browser. Every time you save
a change, refresh the browser tab to see it.
